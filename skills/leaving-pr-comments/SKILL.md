# Leaving PR Comments

Start with the technical conclusion. Cite the relevant code, behavior, or
check, and distinguish what you verified from your judgment. Keep comments
and reviews free of model names, agent or harness signatures, attribution
callouts, session links, and internal review details. Preserve accurate
human contributor credit where relevant.

Before submitting, verify that posting is authorized. Read the final
Markdown, including quotes, links, and attachments, for secrets and private
details. After posting, verify that GitHub returned the comment or review URL.
Resolve a review thread only after the response was posted successfully and
the thread is yours to resolve.
